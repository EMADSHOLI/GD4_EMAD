# My Little Farm — مزرعتي الصغيرة

مشروع التسليم النصفي، &#x20;

لعبة مزرعة من منظور الشخص الأول للكمبيوتر. ينظّف اللاعب الأرض ويزرع المحاصيل ويعتني بها، ثم يحصدها ويبيعها ليجمع المال ويشتري بقرة.

## معلومات المشروع

- اسم مشروع Unity: `GD4_EMAD`
- إصدار Unity: `2022.3.62f3`
- المنصة: Windows
- نمط اللعب: لاعب واحد



## الأنظمة الموجودة

- إزالة الأعشاب قبل الحراثة.
- الحراثة والزراعة والسقي والتسميد والنمو والحصاد.
- شريط تقدم وحركة لليدين أثناء العمليات.
- عدّاد للمحاصيل ورصيد مالي وصناديق للبيع.
- متجر يتيح شراء بقرة وإظهارها في المزرعة.
- خريطة مصغرة تتبع موقع اللاعب واتجاهه.
- ثماني مهام مع عرض حالة إنجازها.
- قائمة رئيسية وإعدادات وحفظ واستكمال.

## هدف اللاعب

نظّف قطعة أرض، واحرثها وازرعها واسقها، ثم احصد المحاصيل بعد نموها وبعها في صندوق البيع. اجمع الرصيد اللازم لشراء بقرة وإنجاز المهام الثماني.

## حالة المشروع والمشكلات المعروفة



- شراء البقرة متاح؛ بقية فئات المتجر ما زالت قيد التطوير.
- بعض عناصر البيئة ما زالت مؤقتة وتحتاج تحسينًا فنيًا.
- أنظمة الطقس وتعاقب الأيام والنوم والقصة وترميم الأبنية مخططة للتطوير لاحقًا.
- مودل اليدين قيد التطوير&#x20;
- خلل في ترتيب اللعب&#x20;

## المساهمات والمصادر

التصاميم التي أنجزتها

- لوحة الارشاد
